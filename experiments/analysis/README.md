# Analysis

- `analyze_utility_results.py`: validates and summarizes the fixed-institution
  benchmark.
- `analyze_online_q_planner.py`: descriptive analysis of the learned Q policy.
- `analyze_paper_results.py`: applies the paper's paired and clustered
  uncertainty calculations and writes the compact result tables used for the
  reported comparisons.
- `utility_plotting.py`: plotting helpers used by the fixed-institution analysis.
