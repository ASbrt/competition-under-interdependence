# Experiments

The experiment code follows the order used in the paper:

- `main/`: fixed-institution benchmark and behavioral-composition sweeps.
- `adaptive/`: scarce coordination capacity, Q-learning planner, paired
  comparison policies, and the counterfactual branch diagnostic.
- `analysis/`: fixed-benchmark analysis, adaptive-planner descriptives, and the
  paper-level statistical tables.
- `visualization/`: generation of the four main paper figures.
- `outputs/`: stored experiment outputs and derived paper results.

See [../docs/experiments.md](../docs/experiments.md) for the mapping from each
script to its role in the paper.
